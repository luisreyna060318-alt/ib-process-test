# 03 · Estatus del pallet


El estatus de cada pallet se muestra como una etiqueta de color. El estatus **no se captura**: lo calcula el sistema a partir de los datos capturados.

| **Estatus**                 | **Significado para el usuario**                                      |
|-----------------------------|----------------------------------------------------------------------|
| Borrador                    | Faltan datos de la solicitud (Etapa 1)                               |
| Solicitado                  | Solicitud completa; aún no cruza a JuP1                              |
| Importado                   | Ya cruzó El Paso → JuP1; inicia el plazo IMMEX                       |
| En retrabajo                | MFO trabaja el material                                              |
| Pendiente HSE               | Hay scrap sin confirmación oficial de HSE                            |
| Pendiente exportación       | Material en LOW sin pedimento de exportación                         |
| Riesgo arancelario          | Riesgo de pagar aranceles: plazo por vencer, faltante o discrepancia |
| Exportado                   | Cerrado: todo exportado (y el scrap confirmado)                      |
| Scrap confirmado            | Cerrado: 100 % destruido con confirmación de HSE                     |
| Cerrado c/aranceles pagados | Cerrado con discrepancia y aranceles pagados (o cierre F4)           |
| Cancelado                   | No se importó                                                        |
